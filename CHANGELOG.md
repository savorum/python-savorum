# Changelog

## 0.1.0

- Provide an async HTTPX2 client for local, self-hosted, and Savorum Cloud instances.
- Support personal tokens, library-scoped requests, and caller-owned HTTP clients.
- Read and write recipes with revision checks and idempotency keys. Read meal
  calendars, edit grocery lists, and paginate recipes, revisions, and books.
- Subscribe to library events with cursor-based reconnection and resync notifications.
- Expose the pinned OpenAPI client and raw requests for binary responses.
